# Домашнее задание №1 (текст страницы Яндекс Практикума)

## Домашнее задание №1. Классификация категории товара по названию

### Описание

В каталогах интернет-магазинов каждый товар относится к определённой категории (subject) — от этого зависят навигация по каталогу, поиск и рекомендации. Категорию часто нужно определять по одному только названию товара, при этом число возможных категорий может исчисляться сотнями, а сами названия — быть короткими, неполными и содержать опечатки.

В данной задаче вам предлагается по русскоязычному названию товара предсказать его категорию (subject) — задача многоклассовой классификации текста, в которой участвует около 371 класса.

# ТЗ Kaggle — MEPhI: NLP: Classification: Subject Detection

## Полное описание соревнования (Overview)

**Mephi Students Product Title Subject Detection**

Homework for the MEPhI master’s course on transformers. Predict a product subject (category) from a Russian item title.

### Description

Online shops send their own titles. Search needs one shared taxonomy: платья, кроссовки, серьги, … — 341 classes.

Input: text (title with the shop name stripped). Output: subject as in train.csv.

### Goal

Train a model on train.csv and label every row in test.csv. Test titles do not overlap train titles.

A linear TF-IDF baseline is enough to submit. A small encoder (ruBERT / MiniLM) is the expected level.

### Evaluation

F1-macro on hidden labels. Public leaderboard ≈ 30% of test, private ≈ 70%. Course grade uses private F1 plus the required notebook.

### Submit

```text
id,subject

same ids as test.csv, class strings as in train.
```

### Code requirement

You must attach a clean Kaggle Notebook that:

- produces a valid example/baseline submission;
- produces your real submission;
- can be rerun.

CSV-only submits without that notebook do not count for the course. Details are in Rules.

Metric: **F1-macro** (`sklearn.metrics.f1_score(..., average="macro", zero_division=0)`).

Unweighted mean of per-class F1. Higher is better. Max is 1.0. Rare classes count as much as frequent ones.
